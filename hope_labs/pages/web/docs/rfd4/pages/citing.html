How to cite

What a run used, and what to cite for it.

RFD4-Proteina

Corley N, Didi K, Kazman MW, Brent RI, et al. Biomolecular design through latent reasoning with RFD4-Proteina. Preprint, 2026. rfd4-proteina.org

The code is distributed at github.com/RosettaCommons/RFD4-Proteina under the BSD 3-Clause license, and the released weights are on the Hugging Face Hub as nvidia/RFD4-Proteina. Check the project page for citation updates before submitting: it was a preprint when this page was written.

AtomWorks

Corley N, et al. Accelerating biomolecular modeling with AtomWorks and RF3. bioRxiv, 2025.

It is worth citing for a run from this page rather than only for the model, because it does real work here: it reads your target, converts it to the annotated mmCIF the model consumes, and completes the atoms missing from it.

The image a run came from

The model runs from a container image built from the project's own published Dockerfile, so the version a run used is the image's. It is on the bar at the foot of this page, read from the install rather than typed here, and the report names it as well.
