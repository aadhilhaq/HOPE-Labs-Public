Getting started

A first run, start to finish, and what to look at when it comes back.

Before you start

Nothing to install. The model is one image file in the HOPE Labs folder and its weights sit beside it, shared rather than copied per run. If the page says the tool is not installed, it is installed from the Set up page, which pulls the image and fetches the weights on a login node.

A first run

  1. Give it a target: a PDB id to fetch, or a file already on Grace.
  2. Name the chains the binder should be designed against, and the hotspots it should reach. Without hotspots the binder may grow anywhere on the target, which is a real thing to want and rarely the thing you meant.
  3. Leave the binder length at 70 to 100 for a first run.
  4. Leave Designs to generate at 8 and the sampling steps at 60.
  5. Read the preview under the form. It shows the contig taken off your structure and every condition the model will be given, in the tool's own words.
  6. Press Queue. The run appears on the Runs screen.

What to look at first

When it finishes, open the run and look at the designs. Each is a complex: the target under its own chain letters and the binder under a new one.

Check the first design in a viewer before trusting the list. Nothing in this run ranks the designs, so the order they are listed in is the order they were written in. A binder grown somewhere other than the face you named is the failure this catches, and it is obvious in one look and invisible in any table.

How long it takes

Minutes a design on an A100 for a binder of seventy residues against a small target, with the compile warm-up left off. A larger target, a longer binder or more sampling steps all cost more. The default walltime is generous on purpose, so a first run does not fail on the clock.

The first run after an install is slower than the ones after it: the model's weights are read off shared storage and the image has to be opened. What the messages mean covers the lines that appear while that is happening.
