The Runs screen

Where a queued run appears, what its states mean, and where its folder is.

Where runs go

Each run is a folder under $SCRATCH/rfd3_runs, named for when it was queued. A run started from this page and one started from a card on the canvas go to the same place, so either is listed on the Runs screen whichever way it was started.

States

The screen reads Slurm rather than guessing from files: queued, running, finished, failed. A run whose job has left the queue without writing designs.json is shown as failed even if the structures are there, because the record the next card reads is what makes a run usable.

Queue again

Queue again submits the same job script afresh. There is no checkpoint to carry on from, so this is a restart rather than a resume; the previous run's folder is left alone.

Adding measures

A run queued from this page is given its MM-GBSA and binder strain by a job of its own, queued behind the design job (what the two are). A run that finished before that, or whose job did not finish, says so in one line over its designs: These designs have no MM-GBSA or binder strain. Add them… opens the Add measures dialog on that run, and Add measures… under the runs list opens it on all of yours.

The dialog lists your runs with what each lacks. Select all takes every run listed, Missing something and Every run choose which are listed, the box finds a run by name, and shift-click takes every run between two. A run with a job already on it, its own design job or a scoring job, is listed but cannot be chosen until that job ends. Each run chosen gets one job on CPU nodes, charged to your usual account and booked for about a quarter of an hour of one core a design.

Nothing already measured is measured again: a design keeps its numbers until its structure changes, and Queue again queues a scoring job behind the new design job.

Cleaning up

A finished run is a few hundred megabytes, mostly structures. The run folders are yours to delete and the shared checkpoint is not in them, so removing one removes only that run.
