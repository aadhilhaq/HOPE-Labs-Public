How to cite

The backbones are RFdiffusion's work and the sequences are ProteinMPNN's. Cite those two, and acknowledge the computing.

RFdiffusion

RFdiffusion is by the Institute for Protein Design at the University of Washington, and it is what designed your backbones. The published paper is:

Watson, J. L. et al. De novo design of protein structure and function with RFdiffusion. Nature 620, 1089 to 1100 (2023). doi:10.1038/s41586-023-06415-8

The install's own README points instead at the preprint, bioRxiv 10.1101/2022.12.09.519842, which was published as the paper above under a different title. The two are the same work, so cite the journal version.

The README also asks that RoseTTAFold be acknowledged, because RFdiffusion builds directly on its architecture and trained parameters. If your methods section goes into how the backbones were made, that belongs in it.

The version this install runs is in the bar along the bottom of the page, read from the install itself rather than typed here, so it names what actually ran.

ProteinMPNN

Every design in the run got its sequence from ProteinMPNN, run with the target held fixed.

Dauparas, J. et al. Robust deep learning based protein sequence design using ProteinMPNN. Science 378, 49 to 56 (2022).

ProteinMPNN is unpacked inside the lab's dl_binder_design checkout, which is where this run finds it. The run calls ProteinMPNN's own script directly and uses none of dl_binder_design's other steps, so none of its AlphaFold or PyRosetta pieces are involved and none of them need citing for a run from this page.

The viewer

A run from this page can be opened in HOPE Labs' own viewer, under Results. A figure made there cites 3Dmol.js, which draws it, and one that shows a surface cites MSMS as well, which computed the surface:

Rego, N. and Koes, D. 3Dmol.js: molecular visualization with WebGL. Bioinformatics 31, 1322 to 1324 (2015). doi:10.1093/bioinformatics/btu829
Sanner, M. F., Olson, A. J. and Spehner, J.-C. Reduced surface: an efficient way to compute molecular surfaces. Biopolymers 38, 305 to 320 (1996). doi:10.1002/(SICI)1097-0282(199603)38:3<305::AID-BIP4>3.0.CO;2-Y
