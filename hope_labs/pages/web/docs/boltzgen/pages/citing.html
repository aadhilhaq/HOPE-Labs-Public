How to cite

The designs are BoltzGen's work, and its folding step is Boltz-2's. Cite BoltzGen as its authors ask, and acknowledge the computing.

BoltzGen

BoltzGen is by Hannes Stärk and colleagues, and it is what generated, folded and ranked your binders. Its repository asks for this:

Stärk, H. et al. BoltzGen: Toward Universal Binder Design. bioRxiv (2025). doi:10.1101/2025.11.20.689494

It is a preprint, with no journal version yet, so that is the reference to use. The installed package itself ships no citation file, so this is taken from the project's own repository at github.com/HannesStark/boltzgen, which is also where to check whether a journal version has appeared.

The version this install runs is in the bar along the bottom of the page, read from the environment itself rather than typed here, so it names what actually ran.

Boltz-2

BoltzGen's folding step re-folds each design with the target using Boltz-2, and its affinity step uses Boltz-2 as well, so two of the model files in the shared cache are Boltz-2's. BoltzGen's own repository asks only for the reference above and carries no Boltz-2 citation, so if your methods section goes into how the designs were scored, take that reference from Boltz-2's own project rather than from here.

The viewer

A run from this page can be opened in HOPE Labs' own viewer, under Results. A figure made there cites 3Dmol.js, which draws it, and one that shows a surface cites MSMS as well, which computed the surface:

Rego, N. and Koes, D. 3Dmol.js: molecular visualization with WebGL. Bioinformatics 31, 1322 to 1324 (2015). doi:10.1093/bioinformatics/btu829
Sanner, M. F., Olson, A. J. and Spehner, J.-C. Reduced surface: an efficient way to compute molecular surfaces. Biopolymers 38, 305 to 320 (1996). doi:10.1002/(SICI)1097-0282(199603)38:3<305::AID-BIP4>3.0.CO;2-Y
