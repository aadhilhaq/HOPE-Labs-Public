The sequence

One protein chain, what the page does with what you paste, and what the limits are.

One chain, protein, nothing else

BioEmu samples a single protein chain. It has no alphabet for a nucleic acid and no way to be given a ligand, a metal or a modified residue, so the page refuses anything outside the twenty amino acids rather than quietly dropping it. A sequence with a U in it, or with X standing in for something unknown, is refused with the letter named.

That means a complex cannot be sampled here. If what you want is the spread of a complex, that is a simulation, and HOPE-MD is the tool for it. What you can do is sample each chain on its own and compare each against the simulation of the complex.

A structure, read for its chain

A structure is the better way in: the chain's sequence is read off the file, so what is sampled is the chain you meant rather than the one you typed, and the file is kept with the run so the samples can be measured against it. Choose a structure opens the structure browser, which reaches this computer, a PDB code, your scratch, your home folder, the run folders of the lab's tools and your group's folder from one dialog. The browser lists .pdb, .ent, .cif and .mmcif files, and inside a run folder of ours it offers the structure that run holds.

What the page does with what you paste

Anything reasonable is accepted and cleaned as you type. A FASTA header is dropped, line breaks and spaces are removed, numbers from a numbered listing are removed, and lower case is raised. The page then says how many residues it ended up with, which is the number worth checking before you submit: a sequence pasted out of a PDF often loses a line.

How long a chain can be

Two different limits, and they mean different things.

About 500 residues is what BioEmu was trained within. Past it the samples are an extrapolation rather than a prediction. The page says so and lets you carry on, because looking is often worth it, but a number taken from such a run should be reported with that sentence attached.

1200 residues is the hard ceiling here. Sampling holds the whole chain on the card and the memory it needs grows with the square of the length, so a longer chain does not run slowly, it runs out of card memory. The page refuses rather than letting a booking die at the end.

A long protein is usually best sampled a domain at a time. Domains move within themselves and against each other, and the second kind of motion is not something a sequence model of this generation claims to get right anyway.

The name of a run

A run is named for you from its length and the first few residues, which is enough to tell two runs apart in a list. Give it your own name when you are going to come back to it: the name is the run's folder on the cluster, so it is what you will be reading in six months.

Giving your own alignment

Set Alignment to a file and name an .a3m you already have, and the search is skipped entirely. That is the right thing to do when you have a curated alignment, when you are sampling the same sequence repeatedly, or when the ColabFold server is down. The file is read as it stands and must end in .a3m: BioEmu decides what a file is by its suffix, and a .fasta named here would be read as a bare sequence.
