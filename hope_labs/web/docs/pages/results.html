Results

The run folders of every tool in one list, newest first, each beside the step that usually follows it.

What is listed

Results looks in the folders each tool writes its runs to, on the cluster, over the connection already open, and lists the twelve newest runs in each folder, newest first. A run is listed by its folder's name, with the full path under it, the tool that made it, and how long ago the folder was last modified.

These are where each tool writes when it is not told otherwise, which is how HOPE Labs starts them. A run written somewhere else is not listed; open it from its own tool.

RFdiffusion, RFdiffusion3, BoltzGen, Boltz-2 and ColabFold are the tools whose page is part of HOPE Labs, and for them that folder is your own scratch and nowhere else. Their output is measured in gigabytes, and a folding run leaves several megabytes of alignment for every protein sequence in it before a structure is written at all, so there is nowhere else for it to go.

Refresh looks again. Otherwise what was read is kept for twenty seconds, so moving between the views does not ask the cluster each time.

The buttons along the top show one tool's runs, with the number of its runs beside its name. Pick it again, or All tools, to see every run.

Results lists folders; it does not read them. A folder is listed whether the run in it finished, failed or is still going. Open the run in its own tool to see which.

Looking at what a run made

Click a run, or its What it made button, and it opens in place into what it made, in the order people look: a report the tool wrote up, a video of the trajectory, the pictures, the structures and the tables. Pictures are drawn small straight away and open large when clicked. A structure turns in a viewer, drawn as a rainbow for one chain, by chain for a complex, and as sticks for anything small, such as a peptide or a docked pose on its own, with the other ways a press away. Surface draws its molecular surface, colored by chain, computed by MSMS on the cluster: the surface a probe the size of a water molecule traces as it rolls over the atoms, with the waters left out. Where MSMS is not installed, or cannot triangulate the structure, the viewer draws a surface of its own and says why under it. A video plays, a report opens as a page, and a table reads as a table and sorts by any heading; a file that holds several tables, as MMPBSA's frames do, has a button for each. Anything can be downloaded, and so can the whole run, zipped on the cluster first because a finished run is thousands of small files.

Open in the tool opens that tool on this run's own results page, with the run already chosen, for every tool. All files lists everything in the folder, for whatever the gallery does not show.

This reads the run's folder rather than asking the tool, so it works the same for every tool, and on a flow too: each card of a flow has a Results button of its own. What it will read is any folder on the cluster your account can read, which is exactly what you could read in a terminal; a folder you may not read says so, rather than looking empty.

Browsing the files

Browse files at the top of Results opens the structure browser, the same dialog every page of ours opens: with your scratch, your home, each tool’s results and the group’s folders down the left. Walk to a folder and press Show what is in it, and everything in it is listed, with Download beside each file. All files on a run opens that same listing on the run’s own folder. Up goes one folder at a time as far as /, and any folder your account can read opens; one it cannot read says why, and the folder you were in stays open.

Handing a run on

The last column holds the step that usually follows a run of that kind: Simulate these designs in HOPE-MD beside a design run, Simulate a complex in HOPE-MD beside a Boltz-2 run and Simulate a structure in HOPE-MD beside a ColabFold one. Pressing one opens the tool that takes the run, in its own tab, which shows the run's folder with a Copy path button and copies it for you on the way to the tool: see Handing on a run. Paste the path into that tool's import box.

A HOPE-MD run says none there: nothing in the lab's order of work comes after a simulation.
