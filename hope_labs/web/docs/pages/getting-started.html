Getting started

Download HOPE Labs, sign in to your cluster once, set it up there the first time, and let its tabs reach this computer.

What you need

  • An account on a cluster with Slurm, such as Grace at Texas A&M HPRC, where you sign in with your password and Duo on your phone.
  • A browser on the same computer. HOPE Labs opens its page in your default browser; the instructions here are for Chrome.
  • A folder on the cluster for HOPE Labs and the tools, with room to spare: your scratch, or a group folder if others will use it too. The first time you sign in, HOPE Labs offers to set itself up there and to install the tools you tick: Setting up on a cluster.

Download and start it

ComputerDownloadThe first time
WindowsHOPE-Labs-windows.zipUnzip the whole folder, not only the program, and run HOPE-Labs.exe inside it. It is not signed, so Windows says Windows protected your PC: choose More info, then Run anyway.

Both downloads are on the releases page of the HOPE Labs repository. From the source:

pip install paramiko
python -m hope_labs

Signing in

HOPE Labs opens a small window first. It is the sign in, and it stays open while you work: closing it signs you out.

BoxWhat goes in it
ClusterGrace (TAMU), ACES (TAMU), or Other (SLURM) for any other cluster with Slurm. ACES signs in with a certificate rather than a password.
AddressFilled in when you pick the cluster: grace.hprc.tamu.edu.
NetIDYour NetID alone, such as jdoe. If you type your TAMU email address, the part before the @ is used, and the log says so.

Press Sign in and open HOPE Labs. Grace asks for your password, then Duo asks how you want to approve. Each question arrives in a small window of its own, with the text exactly as Grace sent it; answer it as you would in a terminal. When you have approved, the panel called What is happening says Signed in on and the login node's name, then HOPE Labs is open, and the page opens in your browser by itself.

One Duo approval covers every tool. HOPE Labs holds the one connection for as long as you are signed in, and every tool you open goes through it.

If the page does not open, Open the page in the same window opens it again, and the log shows its address to paste into a browser. The address carries a token that only this session knows, so keep it to yourself; it changes every time you sign in.

The boxes are remembered for next time, in a file called .hope_labs.json in your home folder on your own computer. Your password is never kept. The same file can point HOPE Labs at tools installed somewhere else.

Let its tabs open

Each tool opens in a tab of its own, on the tool's own page, served from your computer through the connection HOPE Labs holds. A tab opened by your click is not a pop-up, so Chrome lets it open. If nothing opens at all, Chrome blocked it: click the blocked mark at the right of the address bar, choose Always allow, and pick the tool again.

Chrome remembers that answer for the page's address, and the address includes its port. HOPE Labs asks for the same port every time you sign in, worked out from your account name, so the answer holds from one session to the next. If that port is busy, the log says which port the page is on instead, and Chrome may ask once more.

Next

The page that opens is the Tools page, with a block for each tool under the four category buttons. On a cluster new to HOPE Labs it offers to set HOPE Labs up first: see Setting up on a cluster. Then pick a tool and press Launch.

Two more views sit beside it in the column on the left. Flows draws several tools as one graph and queues them together, read as a plan first: see Flows. Results lists every tool's run folders in one place, each beside the step that usually follows it: see Results.
