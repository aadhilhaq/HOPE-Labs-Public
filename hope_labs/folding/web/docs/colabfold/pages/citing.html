How to cite

The folding is not the lab's work. These are the papers and the licenses of the people whose work a run on this page actually does.

ColabFold

Mirdita, M., Schütze, K., Moriwaki, Y., Heo, L., Ovchinnikov, S., and
Steinegger, M. ColabFold: making protein folding accessible to all.
Nature Methods 19, 679 to 682 (2022). doi:10.1038/s41592-022-01488-1

ColabFold is released by its authors under the MIT license, with the copyright held by Sergey Ovchinnikov. Its README names Sergey Ovchinnikov, Milot Mirdita and Martin Steinegger as its authors.

AlphaFold

The folding itself is AlphaFold's. Every run on this page uses the multimer weights, so cite both of these:

Jumper, J. et al. Highly accurate protein structure prediction with AlphaFold.
Nature 596, 583 to 589 (2021). doi:10.1038/s41586-021-03819-2
Evans, R. et al. Protein complex prediction with AlphaFold-Multimer.
bioRxiv (2021). doi:10.1101/2021.10.04.463034

The AlphaFold code in this install is DeepMind's, under the Apache license, version 2.0. The weights carry their own terms, Creative Commons Attribution 4.0 International, and the license text is in the install beside them.

The alignment server, and the databases behind it

The alignment came from the ColabFold MSA server, which searches UniRef and the environmental databases. ColabFold writes the full list for the exact configuration that ran into cite.bibtex in the run folder, and that file is the one to use: it names the MMseqs2, UniRef30 and MGnify papers as well, and only the ones that actually applied.

The viewers

If a figure came out of the viewer on the Runs screen:

Rego, N. and Koes, D. 3Dmol.js: molecular visualization with WebGL.
Bioinformatics 31, 1322 to 1324 (2015). doi:10.1093/bioinformatics/btu829
Sehnal, D. et al. Mol* Viewer: modern web app for 3D visualization and analysis
of large biomolecular structures. Nucleic Acids Research 49, W431 to W437 (2021).
doi:10.1093/nar/gkab314

A run from this page can also be opened in HOPE Labs' own viewer, under Results. A figure made there cites 3Dmol.js, as above, and one that shows a surface cites MSMS as well, which computed the surface:

Sanner, M. F., Olson, A. J. and Spehner, J.-C. Reduced surface: an efficient way to
compute molecular surfaces. Biopolymers 38, 305 to 320 (1996).
doi:10.1002/(SICI)1097-0282(199603)38:3<305::AID-BIP4>3.0.CO;2-Y
