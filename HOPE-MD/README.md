# HOPE-MD, as HOPE Labs carries it

Molecular dynamics of docked complexes on Grace and ACES, by the HOPE Lab. HOPE Labs' **Set up**
installs it from this folder into your HOPE Labs folder (`HOPE-MD/MD`, with its environment beside
it in `HOPE-MD/env`) and checks it with a Prepare job on the queue; the HOPE-MD tile then opens it.
Its documentation is behind **Docs** on its own page. `BUNDLED` names the version this is.

To install it without Set up, on a login node: copy this folder to `<folder>/HOPE-MD/MD`, then run
`bash <folder>/HOPE-MD/MD/install.sh <folder>`.
